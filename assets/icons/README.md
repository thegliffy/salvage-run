# Card icons

Redistributable Game-icons glyphs, tinted to card-kind colour. `UITheme.art()`
loads `res://assets/icons/` plus the `icon` field from `content/cards.json`.

Drop the PNGs (and the `.import` sidecars Godot generates) in this directory.
